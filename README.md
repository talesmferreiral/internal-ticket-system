# 📊 Sistema de Gestão de Chamados Internos | Internal Ticket Management System

---

## 🇧🇷 Português

### 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte da disciplina de Prototipagem de Sistemas no 1º semestre de Ciência da Computação.

O objetivo foi analisar um processo organizacional e propor uma solução digital para melhorar a eficiência operacional, reduzindo problemas como retrabalho, atrasos e falta de controle.

---

### ⚠️ Problema Identificado

A organização analisada utiliza um processo manual e descentralizado para gerenciar solicitações internas (chamados), utilizando e-mails, mensagens e comunicação verbal.

Isso gera:

* Falta de controle das demandas
* Perda de informações
* Retrabalho
* Atrasos no atendimento
* Baixa rastreabilidade

---

### 🔄 Modelagem do Processo (AS-IS)

O processo atual foi modelado utilizando BPMN, permitindo visualizar falhas como:

* Ausência de sistema integrado
* Comunicação informal
* Falta de priorização
* Processos manuais

📎 *Diagrama BPMN disponível na pasta /docs*

---

### ⚙️ Requisitos do Sistema

#### ✅ Funcionais

* Cadastro de chamados
* Acompanhamento de status
* Priorização automática
* Atribuição de responsáveis
* Registro de histórico
* Notificações
* Relatórios (KPIs)

#### ⚙️ Não Funcionais

* Desempenho
* Segurança
* Usabilidade
* Disponibilidade
* Escalabilidade

---

### 🎯 Solução Proposta

Foi proposta a criação de um sistema digital integrado com foco em:

* Centralização das informações
* Automação de processos
* Melhoria da comunicação
* Geração de indicadores
* Aumento da eficiência

---

## 🇺🇸 English

### 📌 About the Project

This project was developed as part of a Systems Prototyping course during the first semester of a Computer Science degree.

The goal was to analyze an organizational process and propose a digital solution to improve operational efficiency, reducing issues such as rework, delays, and lack of control.

---

### ⚠️ Problem Description

The organization analyzed manages internal requests (tickets) through manual and decentralized processes, using emails, messaging apps, and verbal communication.

This results in:

* Lack of control
* Information loss
* Rework
* Delays
* Low traceability

---

### 🔄 Process Modeling (AS-IS)

The current process was modeled using BPMN, highlighting issues such as:

* No integrated system
* Informal communication
* Lack of prioritization
* Manual processes

📎 *BPMN diagram available in the /docs folder*

---

### ⚙️ System Requirements

#### ✅ Functional

* Ticket creation
* Status tracking
* Automatic prioritization
* Task assignment
* Activity history
* Notifications
* Reports and KPIs

#### ⚙️ Non-Functional

* Performance
* Security
* Usability
* Availability
* Scalability

---

### 🎯 Proposed Solution

A digital system was proposed focusing on:

* Information centralization
* Workflow automation
* Improved communication
* Performance indicators
* Increased efficiency

---

### 📚 Key Learnings

* Requirements engineering
* Process modeling (BPMN)
* Problem analysis
* Critical thinking
